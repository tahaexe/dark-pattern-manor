# Tech

Build: Vite, TypeScript (strict), Preact, plain CSS with custom properties.

Testing: Vitest, jsdom, @testing-library/preact, fast-check for property-based tests of the room data rules, axe-core checks of rendered rooms.

Deployment: GitHub Pages through GitHub Actions, base path /dark-pattern-manor/. MIT license.

## Runtime privacy

The game sets no cookies, makes no third-party requests, and has no analytics. Progress lives only in localStorage.
