# Structure

- src/main.tsx — entry point
- src/app — routing, progress
- src/engine — room state: haunted → named → honest
- src/rooms/NN-slug — room data, Haunted and Honest components, CSS
- src/guide — Ghost Guide data and card
- src/ui — spell cards, task bar, Before/After slider
- src/styles — tokens, base
- scripts — hook scripts
- .kiro/specs — one folder per feature: requirements in EARS notation, design, tasks
- .kiro/hooks — agent hooks
