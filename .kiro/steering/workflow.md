# Workflow

Work only inside this repository.

Allowed commands: npm, npx vite/vitest/tsc/prettier, node scripts/…, and git status/diff/log/add/init. A PreToolUse hook enforces this. Never commit or push.

Every feature comes with tests.

## Rooms

Every room needs a haunted variant and an honest variant, exactly three spell cards (one correct, one close relative, one clearly different), with a hint for each wrong one.

Keep components small and named after the room and pattern.
