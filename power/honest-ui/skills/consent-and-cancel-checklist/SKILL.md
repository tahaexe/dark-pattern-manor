# Twelve rules to ship by

Run the flow against these twelve before release. Each should be a plain "yes"; a "no" is a dark pattern to fix (see the honest-twin skill). Phrase a finding as "may be a dark pattern; check", never as a claim that a flow breaks the law.

1. "Reject all" is as visible as "Accept all".
2. Every checkbox sentence means what it says when ticked; no double negatives.
3. Declining is a plain "No thanks", never an insult.
4. A free trial shows the price after, the start date and the way to cancel before the button.
5. A countdown is real and states what ends.
6. "Only N left" comes from real stock or is not shown.
7. Reviews are dated and verified; no "people are looking" counters.
8. The basket holds only what the user added.
9. The first price shown is the total.
10. A prompt the user dismissed offers "Don't ask again".
11. Nothing optional is pre-ticked.
12. Cancelling takes no more steps than signing up, and ends with a confirmation.
