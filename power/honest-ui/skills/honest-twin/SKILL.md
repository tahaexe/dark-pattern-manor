# The honest twin

Take the flagged screen and rebuild it as the honest version of the same task. The honest twin does the same job; it just stops steering the choice. Change the smallest thing that removes the trick.

- **Equal choices.** Accept and refuse are buttons of the same size, weight and colour family, side by side, in the first layer. Neither is hidden, faded or one layer down.
- **Plain words.** One positive sentence per checkbox; ticking means yes. A decline is a plain "No thanks", never an insult or a double negative.
- **Prices up front.** Show the total with every fee before the user commits. A trial states the price after, the date it starts and how to cancel, next to the button that starts it.
- **Honest defaults.** Nothing optional is pre-ticked. Nothing reaches the basket the user did not add.
- **Honest time and stock.** A countdown appears only for a real deadline, and says what ends. A stock count ("only N left") comes from real stock, or is not shown.
- **A way out as easy as the way in.** Cancelling takes no more steps than signing up, and ends with a confirmation the user can keep.
- **Still usable by everyone.** Keep the honest version operable by keyboard and screen reader, with all text at WCAG AA contrast.

Phrase any change as "may be a dark pattern; check" — never as a claim that a flow breaks the law — and name no real company.
